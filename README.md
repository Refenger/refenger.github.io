# RefEngine — документация

Сайт: **https://refenger.github.io/**

Документация RefEngine — движка Friday Night Funkin' на LÖVE 11.5. Сайт собирается из Markdown-файлов в `docs/` с помощью [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) и публикуется на GitHub Pages сам при каждом изменении ветки `main` (`.github/workflows/deploy.yml`).

## Посмотреть локально

```
pip install -r requirements.txt
mkdocs serve
```

и открыть http://127.0.0.1:8000.
