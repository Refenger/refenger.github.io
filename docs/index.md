# RefEngine

**RefEngine** — движок для модов [Friday Night Funkin'](https://ninja-muffin24.itch.io/funkin) на [LÖVE](https://love2d.org/) 11.5. Песни, персонажей, сцены, нотскины и свои типы нот в нём делают во встроенных редакторах, без программирования. Скрипты на Lua добавляются, когда нужно что-то сверх этого.

## Инструменты разработчика

Все редакторы открываются из главного меню, пункт **«Инструменты разработчика»**:

| Редактор | Что в нём делают |
|---|---|
| Редактор персонажей | Персонаж из спрайтшита: анимации, оффсеты, иконка и её цвет для шкалы здоровья. |
| Редактор нотскинов | Стрелки, длинные ноты и сплеши: из слоёв или из спрайтшита, для любой раскладки. |
| Редактор типов нот | Свои типы нот: картинка, внешний вид на каждой линии, правила попадания, скрипт. |
| Редактор сцен | Слои сцены, точки персонажей, камера, освещение. |
| Редактор чартов | Ноты песни по дорожкам, смены управления, маркеры; запуск песни прямо из редактора. |
| Универсальный конвертер | Чарты из других игр в песни движка. Пока — osu!mania (`.osz` / `.osu`). |

Всё, что сохраняют редакторы, по умолчанию попадает в мод **My Saves** в папке сохранений игры. Он есть у каждого игрока и стоит выше остальных модов.

## Полезные клавиши в игре

| Клавиша | Что делает |
|---|---|
| `-` / `+` | Громкость −5% / +5% (из любого места игры) |
| `F3` | Показать / скрыть счётчики FPS и памяти |
| `F11`, `Alt+Enter` | Полноэкранный режим |
| `7` | В песне, запущенной из редактора чартов: вернуться в редактор |
