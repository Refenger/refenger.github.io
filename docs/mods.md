# Моды

Мод в RefEngine — это папка внутри `mods/`, которая устроена как вторая копия папки игры. Когда игра ищет файл, например `assets/noteskins/Default/data.json`, она сначала смотрит в модах и только потом в своих файлах. Мод может заменить любой файл игры или добавить новый.

## Где лежат моды

Моды ищутся в двух местах:

- в папке `mods/` рядом с игрой;
- в папке `mods/` в папке сохранений игры (на Windows: `%APPDATA%\LOVE\<игра>\mods`).

## Устройство мода

```
mods/<Мой мод>/
├── mod.json             ← название и описание мода
├── assets/
│   ├── characters/      ← персонажи
│   ├── noteskins/       ← нотскины
│   ├── notetypes/       ← типы нот
│   └── stages/          ← сцены
└── songs/
    └── <Песня>/         ← песни (см. «Песни и чарты»)
```

Папки повторяют структуру игры: файл `mods/<мод>/assets/characters/BF/main.json` заменяет `assets/characters/BF/main.json` игры. Нужны только те папки, которые мод использует.

## mod.json

```json
{
  "name": "Russian Volumes",
  "description": "FNF Russian Volumes: песни, сцена, нотскин и меню мода",
  "version": "1.0",
  "engine": "RefEngine"
}
```

| Поле | Что значит |
|---|---|
| `name` | Название мода в меню модов. Без него показывается имя папки. |
| `description` | Описание мода. |
| `version`, `engine` | Версия мода и движок, для которого он сделан. |

## Порядок модов

Если один и тот же файл есть в нескольких местах, побеждает первое:

1. **My Saves** — то, что сохранили редакторы (всегда первым);
2. включённые моды, по порядку;
3. файлы самой игры.

!!! note "My Saves"
    Мод **My Saves** создаётся сам в папке сохранений. Туда по умолчанию сохраняют все редакторы: песни, персонажей, сцены, нотскины, типы нот. Поэтому отредактированный файл заменяет оригинал из мода, а сам мод остаётся нетронутым.

## Меню модов

Пункт **«Моды»** в главном меню показывает все найденные моды. Клик по моду включает или выключает его. Выбор сохраняется в файле `mods.json` в папке сохранений и действует сразу. Выключенный мод не накладывается на игру: его песни, персонажи и всё остальное пропадают из игры, пока его снова не включат.
