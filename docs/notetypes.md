# Типы нот

Тип нот — это своя нота мода: свой внешний вид, свои правила попадания и, при желании, свой скрипт. Нота в чарте относится к типу, если её поле `type` — имя типа. Обычные ноты имеют `type: 0`.

Типы нот создают в **редакторе типов нот** (Инструменты разработчика → Редактор типов нот).

## Папка типа

```
assets/notetypes/<Тип>/
├── image.png            ← картинка ноты
├── image.xml            ← спрайтшит (Sparrow XML), необязательно
├── data.json            ← внешний вид и правила
└── scripts/
    └── main.lua         ← скрипт типа, необязательно
```

- **С `image.xml`** нота может быть любой анимацией из спрайтшита, многокадровые проигрываются.
- **Без него** вся картинка — один кадр ноты.

## Внешний вид

Для каждой раскладки (1K, 4K, 7K… — без ограничения) и каждой её линии отдельно задаётся:

| Что | Значение |
|---|---|
| Нота | Анимация из спрайтшита. Не задано — первая анимация (без XML — вся картинка). |
| Хвост | Хвост длинной ноты: анимация или «из нотскина» (по умолчанию). |
| Конец хвоста | То же для конца хвоста. |
| Поворот | Поворот ноты в градусах. |

Для всего типа задаются:

- **размер ноты**, % (100 — как обычная нота);
- **смещение** каждой анимации в px спрайтшита (без XML — одно на всю картинку). Смещение поворачивается вместе с нотой. У хвоста и конца хвоста действует только смещение по X.

!!! tip "Предпросмотр"
    В правом верхнем углу редактора нота типа подлетает к страму рядом с обычной нотой, и их удобно сравнивать. Там же полосой показано окно попадания.

Если для раскладки дорожки у типа нет настроек, в игре его нота — первая анимация без поворота, а хвост берётся у нотскина.

## Правила в игре

Вкладка **«Игра»** в редакторе:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Попадание считается промахом | выкл. | Нажатие ноты засчитывается как промах (счётчик промахов, анимация промаха, заглушённые голоса). Пропуск — не промах. Бот такие ноты не нажимает. |
| Окно попадания: раньше, мс | 166 | Насколько раньше своего времени ноту можно нажать. |
| Окно попадания: позже, мс | 166 | Насколько позже ещё можно. После этого нота считается пропущенной. |
| Здоровье: попал | +8 (−5 у «вредной») | Изменение здоровья (из 100) за попадание. |
| Здоровье: пропустил | −5 (0 у «вредной») | Изменение здоровья за пропуск. |

Любая нота, пропущенная или нет, пролетает за страм ещё 300 мс и только потом исчезает, каким бы ни было окно попадания.

## data.json

Всё это редактор пишет сам. Для справки:

```json
{
  "scale": 1,
  "layouts": {
    "4": [
      {"anim": "left", "sustain": "left hold", "sustain_end": "left hold end", "rotation": 0},
      {"anim": "down", "rotation": 0}
    ]
  },
  "offsets": {
    "left": {"x": 0, "y": -4}
  },
  "hitIsMiss": true,
  "hitEarly": 100,
  "hitLate": 60,
  "healthHit": -20,
  "healthMiss": 0
}
```

| Поле | Что значит |
|---|---|
| `scale` | Размер ноты (`1` = 100%). |
| `layouts` | По раскладкам (ключ — число линий строкой), по линиям: `anim`, `sustain`, `sustain_end` — имена анимаций (`"@image"` — вся картинка; у хвостов нет значения — из нотскина), `rotation` — поворот. |
| `offsets` | Смещение анимаций: ключ — имя анимации или `"@image"`. |
| `hitIsMiss`, `hitEarly`, `hitLate`, `healthHit`, `healthMiss` | Правила с вкладки «Игра». Не указано — значение по умолчанию. |

## Тип ноты в чарте

В редакторе чартов:

- у выбранной ноты тип меняется в панели ноты, поле **«Тип ноты»**;
- тип для новых нот выбирается в меню **Чарт → Тип новых нот**.

Ноты с типом в редакторе рисуются картинкой своего типа.

## Скрипт типа

Кнопка **«Открыть скрипт»** создаёт `scripts/main.lua` из шаблона (если его ещё нет) и открывает его в программе, которая назначена в системе для `.lua`. Скрипт загружается, если в чарте песни есть ноты этого типа, и один обслуживает все ноты своего типа. Подробнее — в разделе [Скрипты](scripting/index.md#скрипты-типов-нот).
