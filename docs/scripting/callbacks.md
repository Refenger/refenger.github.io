# Колбэки

Колбэк — функция скрипта, которую игра вызывает сама в определённый момент. Объявить её можно двумя способами:

```lua
-- 1. В таблице, которую возвращает main.lua (рекомендуется)
local script = {}
function script.update(dt) end
return script

-- 2. Глобальной функцией в main.lua
function update(dt) end
```

- Если `main.lua` вернул таблицу, функция ищется сначала в ней, потом среди глобальных.
- Колбэк, которого нет, просто не вызывается: объявляйте только нужные.
- Колбэки вызываются только во время песни. В меню и редакторах скрипт не работает.
- Возвращаемое значение колбэка игра не использует.

Всего колбэков девять: [`create`](#create), [`createPost`](#createpost), [`update`](#updatedt), [`onStep`](#onstepstep), [`keypressed`](#keypressedkey), [`keyreleased`](#keyreleasedkey), [`onNoteSpawn`](callbacks.md#onnotespawnnote), [`onNoteHit`](callbacks.md#onnotehitnote), [`onNoteMiss`](callbacks.md#onnotemissnote). Других нет.

## Порядок вызова

```
вход в песню
│
├─ код верхнего уровня main.lua    (один раз, при загрузке скрипта)
├─ create()                         (один раз)
│     … игра создаёт слои стадии, персонажей, дорожки и ноты, запускает музыку …
├─ createPost()                     (один раз)
│
├─ каждый кадр, пока играет песня:
│     ├─ onNoteSpawn / onNoteHit (бот) / onNoteMiss   (по разу на каждую такую ноту)
│     ├─ onStep(step)               (0, 1 или несколько раз: по разу на каждый новый шаг)
│     └─ update(dt)                 (один раз)
│
├─ в любой момент между кадрами:
│     ├─ keypressed(key)
│     │     └─ onNoteHit(note)      (если нажатие попало по ноте игрока: до keypressed)
│     └─ keyreleased(key)
│
└─ песня закончилась → выход в меню (больше ничего не вызывается)
```

## Код верхнего уровня `main.lua`

Это не колбэк, но тоже момент, когда выполняется код скрипта: всё, что написано в `main.lua` вне функций, выполняется один раз при загрузке скрипта.

- **Когда:** первым, до загрузки стадии, персонажей и нот.
- **Подходит для:** `require` модулей, объявления переменных и констант, подготовки таблиц.
- **Если упадёт:** скрипт не подключается совсем, и песня идёт без него.

```lua
local counter = require("utils.counter")   -- модули грузятся здесь
local SHAKE_POWER = 30                      -- константы
local beats = counter.new("beats")          -- состояние скрипта
```

## `create()`

- **Аргументы:** нет.
- **Когда:** один раз, сразу после загрузки стадии (её `stage.json` и скрипта стадии), но до того как созданы её слои, персонажи, дорожки и ноты. Музыка ещё не играет.
- **Подходит для:** загрузки своих ресурсов заранее (`love.graphics.newImage`, `love.audio.newSource`), чтобы не грузить их посреди песни.

```lua
local hitSound

function script.create()
    hitSound = love.audio.newSource("songs/Obsoliit/sounds/hit.ogg", "static")
end
```

## `createPost()`

- **Аргументы:** нет.
- **Когда:** один раз, когда всё создано: стадия, персонажи, дорожки, ноты. Музыка (инструментал и голоса) запущена прямо перед вызовом, первый кадр песни ещё не прошёл.
- **Подходит для:** начальной настройки, которой нужно, чтобы всё уже существовало (когда в API появятся персонажи и дорожки), запуска своих звуков синхронно с песней, засечки времени старта.

```lua
local startTime

function script.createPost()
    startTime = love.timer.getTime()
end
```

## `update(dt)`

- **Аргументы:**
  - `dt` (number) — сколько секунд прошло с прошлого кадра (при 60 FPS около `0.0167`). Это реальное время: оно не зависит от скорости песни.
- **Когда:** каждый кадр, пока играет песня, после всех `onStep` этого кадра. На кадре, где песня закончилась, уже не вызывается.
- **Подходит для:** всего, что меняется плавно: анимаций, таймеров, проверки зажатых клавиш (`love.keyboard.isDown`).
- **Важно:** вызывается очень часто, поэтому не загружайте в нём файлы и не создавайте ресурсы. Для движения умножайте скорость на `dt`, тогда результат не зависит от FPS.

```lua
local angle = 0

function script.update(dt)
    angle = angle + 90 * dt                            -- 90 градусов в секунду при любом FPS
    local wave = math.sin(love.timer.getTime() * 2)    -- от -1 до 1, период ~3.14 с
end
```

## `onStep(step)`

- **Аргументы:**
  - `step` (number, целое) — номер шага, на который перешла песня.
- **Когда:** каждый раз, когда позиция песни переходит на новый шаг. Вызывается до `update` того же кадра.
  - Шаг — 1/16 такта: `длина шага (мс) = 15000 / BPM` (при 120 BPM это 125 мс).
  - 4 шага = 1 бит, 16 шагов = 1 секция.
  - Первый вызов приходит на шаге `1`, шаг `0` не вызывается.
  - Шаги не пропускаются: если кадр подвис и песня проскочила несколько шагов, `onStep` вызовется для каждого по порядку в одном кадре.
  - При ускоренной песне шаги идут чаще: номер шага привязан к позиции в песне, а не к реальному времени.
- **Подходит для:** событий в такт музыке: каждые бит или секцию, или на конкретном шаге.

```lua
function script.onStep(step)
    if step % 4 == 0 then
        -- каждый бит
    end
    if step % 16 == 0 then
        -- начало каждой секции (секция номер step / 16)
    end
    if step == 128 then
        -- один раз: начало 9-й секции
    end
end
```

## `keypressed(key)`

- **Аргументы:**
  - `key` (string) — имя нажатой клавиши, [KeyConstant](https://love2d.org/wiki/KeyConstant) LÖVE: `"a"`, `"1"`, `"space"`, `"return"`, `"escape"`, `"left"`, `"lshift"`, `"f1"`… Имя зависит от текущей раскладки клавиатуры, поэтому одна и та же физическая клавиша при разных раскладках может прийти под разными именами.
- **Когда:** один раз в момент нажатия клавиши, после того как дорожки обработали её как нажатие ноты. При удержании клавиши повторно не вызывается.
  - Не вызывается, пока открыто диалоговое окно игры.
  - Вызывается для любой клавиши, в том числе для клавиш нот и для F11 (которая ещё и переключает полноэкранный режим).
- **Подходит для:** переключателей и одиночных действий по кнопке.
- **Совет:** если нужна физическая клавиша независимо от раскладки, проверяйте в `update` через `love.keyboard.isScancodeDown("a")`.

```lua
local enabled = false

function script.keypressed(key)
    if key == "1" then
        enabled = not enabled
        print("Эффект " .. (enabled and "включён" or "выключен"))
    end
end
```

## `keyreleased(key)`

- **Аргументы:**
  - `key` (string) — имя отпущенной клавиши, такое же, как в `keypressed`.
- **Когда:** один раз в момент отпускания клавиши, после того как её обработали дорожки.
- **Подходит для:** действий, которые длятся, пока клавиша зажата: начать в `keypressed`, закончить здесь.

```lua
local charging, charge = false, 0

function script.keypressed(key)
    if key == "space" then charging, charge = true, 0 end
end

function script.update(dt)
    if charging then charge = charge + dt end
end

function script.keyreleased(key)
    if key == "space" then
        charging = false
        print(("Зажато %.2f с"):format(charge))
    end
end
```

## Колбэки нот

Три колбэка ниже получают один аргумент `note` — таблицу с данными о ноте. Это копия: у каждого скрипта своя, и изменение полей ни на что в игре не влияет.

| Поле | Тип | Что значит |
|---|---|---|
| `type` | string или number | Тип ноты: имя типа или `0` у обычной ноты. |
| `lane` | number | Номер дорожки (страмлайна) в чарте, с 1. |
| `column` | number | Номер линии в дорожке, с 1 (в 4K: 1 ←, 2 ↓, 3 ↑, 4 →). |
| `keyCount` | number | Сколько линий у дорожки. |
| `time` | number | Время ноты в песне, мс. |
| `length` | number | Сколько её держать, мс (`0` — обычная нота, не длинная). |
| `player` | boolean | `true` — дорожкой управляет игрок, `false` — бот. |
| `offset` | number или nil | Только в `onNoteHit`: на сколько мс раньше нажата нота (меньше 0 — позже). |

У длинной ноты колбэки получает только её голова: хвост отдельно не сообщается.

## `onNoteSpawn(note)`

- **Когда:** нота появилась на экране, примерно за 2 секунды до своего времени (с учётом скорости песни).
- **Подходит для:** подготовки к ноте заранее: звук, эффект, отсчёт.

## `onNoteHit(note)`

- **Когда:** по ноте попали.
  - Нота игрока — в момент нажатия клавиши, внутри обработки нажатия, до колбэка `keypressed`. `note.offset` показывает, насколько точно.
  - Нота бота — когда до неё осталось 10 мс или меньше (бот не промахивается).
- **Подходит для:** эффекта ноты: например, бомба отнимает здоровье, а особая нота меняет что-то в песне (когда в API появятся нужные функции).

```lua
local notetype = {}

function notetype.onNoteHit(note)
    if note.player then
        print(("Попадание по линии %d, отклонение %.1f мс"):format(note.column, note.offset))
    end
end

return notetype
```

## `onNoteMiss(note)`

- **Когда:** окно попадания ноты игрока закрылось (по умолчанию через 166 мс после её времени, у [типа нот](../notetypes.md) — через его «Позже, мс»), а по ней не попали. Нота при этом ещё пролетает за страм до 300 мс.
- **Подходит для:** наказания или реакции на промах.

## Колбэки LÖVE (`love.update`, `love.draw`, `love.keypressed`…) — не трогать

Модуль `love` открыт скрипту целиком, поэтому технически можно написать `love.update = function() … end`. Делать этого нельзя: так скрипт заменит главный цикл самой игры, и игра перестанет работать, причём не только в этой песне, а до перезапуска. Для своего кода используйте колбэки скрипта, описанные выше.
