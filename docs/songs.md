# Песни и чарты

Песня — это папка в `songs/` мода. Песни есть только в модах: в выборе песни показываются песни всех включённых модов, у которых есть хотя бы один чарт.

## Папка песни

```
songs/<Песня>/
├── meta.json            ← иконка, цвет, BPM, сложности
├── charts/
│   ├── easy.json        ← чарты: один файл на сложность
│   └── hard.json
├── song/
│   ├── Inst.ogg         ← инструментал (обязательно)
│   ├── Voices.ogg       ← голоса игрока (необязательно)
│   └── Opponent.ogg     ← голоса оппонента (необязательно)
└── scripts/
    └── main.lua         ← скрипт песни (необязательно, см. «Скрипты»)
```

Аудио может быть в `.ogg`, `.mp3` или `.wav`. Если голоса игрока заглушаются на промахах, голоса оппонента (`Opponent`) играют всегда.

## meta.json

```json
{
  "character_icon": "ObsoliitMatt",
  "color": "d94c36",
  "bpm": 205,
  "scrollSpeed": 2.6,
  "difficulties": {
    "hard": {"display_name": "Hard", "color": "ea1c2e"}
  }
}
```

| Поле | Что значит |
|---|---|
| `character_icon` | Персонаж, чья иконка показывается у песни в выборе песни (`assets/characters/<имя>/icon.png`). |
| `color` | Цвет фона в выборе песни, `"rrggbb"` или `"#rrggbb"`. |
| `bpm` | Темп песни (если у чарта нет своего `bpm`). |
| `scrollSpeed` | Скорость прокрутки по умолчанию для новых дорожек. |
| `difficulties` | Сложности в нужном порядке: ключ — имя файла чарта без `.json`, `display_name` — название, `color` — цвет кнопки. Чарты, которых здесь нет, идут после. |

Песню удобнее всего создавать и настраивать в **редакторе чартов** (Инструменты разработчика → Редактор чартов → «+ Создать песню»): он сам пишет `meta.json` и раскладывает аудио.

## Чарт

Чарт — файл `charts/<сложность>.json`. Главное в нём — список дорожек `strumLines`: у каждой дорожки свои ноты, персонажи и положение на экране.

```json
{
  "stage": "Obsoliit",
  "bpm": 205,
  "scrollSpeed": 2.6,
  "characters": [{"point": "gf", "character": "GF"}],
  "markers": [{"time": 32000, "name": "Припев"}],
  "strumLines": [
    {
      "position": "boyfriend",
      "characters": ["BF"],
      "type": 1,
      "keyCount": 4,
      "noteSkin": "RV",
      "strumLinePos": 0.75,
      "strumY": 0,
      "strumScale": 1,
      "strumSpacing": 1,
      "scrollSpeed": 2.6,
      "controlChanges": [{"time": 60000, "player": false}],
      "notes": [
        {"id": 0, "time": 9365.8, "sLen": 219.5, "type": 0}
      ]
    }
  ]
}
```

### Поля чарта

| Поле | Что значит |
|---|---|
| `stage` | Сцена (`assets/stages/<имя>`). |
| `bpm` | Темп. Нет — берётся из `meta.json`. |
| `scrollSpeed` | Скорость прокрутки для дорожек без своей. |
| `characters` | Персонажи на сцене, у которых нет своей дорожки: `point` — точка сцены, `character` — персонаж. |
| `markers` | Маркеры времени из редактора чартов: `time` в мс, `name`. |

### Поля дорожки

| Поле | Что значит |
|---|---|
| `position` | Точка сцены, где стоят персонажи дорожки. |
| `characters` | Персонажи, которые поют ноты этой дорожки. |
| `type` | `1` — в начале песни дорожкой управляет игрок, иначе бот. |
| `keyCount` | Число линий (клавиш): 1, 4, 7, 9… |
| `noteSkin` | Нотскин (`assets/noteskins/<имя>`), нет — `Default`. |
| `strumLinePos` | Положение по горизонтали: `0` — левый край экрана, `1` — правый. |
| `strumY` | Сдвиг страмов по вертикали в px (при downscroll — в обратную сторону). |
| `strumScale`, `strumSpacing` | Размер страмов и расстояние между ними (множители). |
| `scrollSpeed` | Скорость прокрутки этой дорожки. Нет — из чарта. |
| `controlChanges` | Смены управления по ходу песни: с момента `time` (мс) дорожкой управляет игрок (`player: true`) или бот. |
| `notes` | Ноты дорожки. |

### Поля ноты

| Поле | Что значит |
|---|---|
| `id` | Линия, с `0` (в 4K: 0 ←, 1 ↓, 2 ↑, 3 →). |
| `time` | Время ноты в песне, мс. |
| `sLen` | Сколько держать, мс. `0` — обычная нота. |
| `type` | `0` — обычная нота, или имя [типа нот](notetypes.md). |

!!! tip "Время и шаги"
    Шаг — 1/16 такта: `длина шага (мс) = 15000 / BPM`. 4 шага — бит, 16 шагов — секция. В редакторе чартов одна секция — один экран дорожки при зуме ×1.

## Проверка песни из редактора

В редакторе чартов **Enter** сохраняет чарт и запускает песню так же, как из выбора песни. Когда песня закончится, или если нажать **7**, игра вернётся в редактор на то же место: та же позиция в песне, вид, зум и расположение дорожек.
